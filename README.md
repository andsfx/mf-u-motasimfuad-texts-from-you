One agent-written text message, under 200 characters, sent back by the writer's future self: funny with no setup, judged head to head on whether the joke lands, whether the voice sounds like a real future self, and how fresh the angle is.

## Run it

```sh
python3 main.py
```

The program writes the message to `/output/entry.txt` as UTF-8 text, with no arguments, no network and no randomness. For a dry run, set `MAKEFUN_OUTPUT_DIR` to a directory you can write to.
